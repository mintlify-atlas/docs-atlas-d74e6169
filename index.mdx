## Why Paper Shaders?

<CardGroup cols={2}>
  <Card title="Zero dependencies" icon="feather">
    Pure WebGL2 — no Three.js, no PIXI, no runtime overhead. Each shader is a self-contained fragment shader string.
  </Card>
  <Card title="Animated by default" icon="play">
    Control speed, direction, and frame offset. Set `speed={0}` for a static, zero-cost render.
  </Card>
  <Card title="Fully typed" icon="typescript" href="/api/shader-types">
    Every shader exposes TypeScript param and uniform types extracted directly from source.
  </Card>
  <Card title="SSR safe" icon="server">
    Undefined uniforms are gracefully skipped, so shaders render without errors during server-side rendering.
  </Card>
  <Card title="Image filters" icon="image" href="/shaders/fluted-glass">
    Apply fluted glass, water distortion, dithering, heatmap, liquid metal, and halftone effects to any image.
  </Card>
  <Card title="Designed in Paper" icon="pen-nib">
    Configure shaders visually in the Paper design tool and export directly to production-ready code.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Install the package">
    Choose the package for your stack.

    <CodeGroup>
    ```bash React
    npm install @paper-design/shaders-react
    ```
    ```bash Vanilla JS
    npm install @paper-design/shaders
    ```
    </CodeGroup>

    <Note>Pin your dependency version. Paper Shaders ships breaking changes under `0.0.x` versioning while the API stabilises.</Note>
  </Step>
  <Step title="Add a shader to your page">
    Import a component and drop it in — it fills its parent container.

    ```tsx
    import { MeshGradient } from '@paper-design/shaders-react';

    export default function Hero() {
      return (
        <div style={{ width: '100%', height: 400 }}>
          <MeshGradient
            colors={['#e0eaff', '#241d9a', '#f75092', '#9f50d3']}
            speed={1}
            style={{ width: '100%', height: '100%' }}
          />
        </div>
      );
    }
    ```
  </Step>
  <Step title="Customise with props">
    Every shader exposes typed props for colors, speed, distortion, sizing, and more. See the [shader reference](/shaders/overview) for all options.
  </Step>
</Steps>
