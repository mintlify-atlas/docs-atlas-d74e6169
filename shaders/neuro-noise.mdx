A glowing, web-like structure of fluid lines and soft intersections. The pattern is built from 15 layers of rotating sinusoidal accumulation, producing bright crossing points that fade into a dark background. Great for creating atmospheric, organic-yet-futuristic visuals.

## Usage

<Tabs>
  <Tab title="React">
    ```tsx
    import { NeuroNoise } from '@paper-design/shaders-react';

    export default function Example() {
      return (
        <NeuroNoise
          colorFront="#ffffff"
          colorMid="#47a6ff"
          colorBack="#000000"
          brightness={0.05}
          contrast={0.3}
          speed={1}
          style={{ width: '100%', height: '100%' }}
        />
      );
    }
    ```
  </Tab>
  <Tab title="Vanilla JS">
    ```ts
    import { ShaderMount, neuroNoiseFragmentShader } from '@paper-design/shaders';

    const container = document.querySelector('#canvas-container');

    const shader = new ShaderMount(container, neuroNoiseFragmentShader, {
      u_colorFront: [1, 1, 1, 1],
      u_colorMid: [0.278, 0.651, 1, 1],
      u_colorBack: [0, 0, 0, 1],
      u_brightness: 0.05,
      u_contrast: 0.3,
    });
    ```
  </Tab>
</Tabs>

## Props

<ParamField path="colorFront" type="string" default="#ffffff">
  Highlight color applied at the brightest crossing points.
</ParamField>

<ParamField path="colorMid" type="string" default="#47a6ff">
  Main color of the network lines.
</ParamField>

<ParamField path="colorBack" type="string" default="#000000">
  Background color.
</ParamField>

<ParamField path="brightness" type="number" default="0.05">
  Luminosity of the crossing intersection points. Range: `0` to `1`.
</ParamField>

<ParamField path="contrast" type="number" default="0.3">
  Sharpness of the bright-to-dark transition. Range: `0` to `1`.
</ParamField>

<ParamField path="speed" type="number" default="1">
  Animation speed multiplier. Set to `0` to pause.
</ParamField>

<ParamField path="frame" type="number" default="0">
  Static frame position when `speed` is `0`.
</ParamField>

## Presets

| Name | Description |
|------|-------------|
| `Default` | Blue neural network on black |
| `Sensation` | Vivid cyan and yellow on purple |
| `Bloodstream` | Red veins on white |
| `Ghost` | Monochrome high-contrast web |
