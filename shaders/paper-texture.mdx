---
title: "Paper Texture"
description: "A static texture built from multiple noise layers, usable for a realistic paper and cardboard surfaces or generating abstract patterns. Can be used as an image filter or as a texture."
---

A static texture built from multiple noise layers — fiber noise, cell-based crumples, fold distortion, roughness, and speckle drops — composited with a directional light model to produce a convincing paper or cardboard surface. Can be used as a standalone texture or as an image filter over an uploaded photo.

## Props

<ParamField path="colorFront" type="string" default="#9fadbc">
  Foreground (highlight/lit surface) color.
</ParamField>

<ParamField path="colorBack" type="string" default="#ffffff">
  Background (shadow/unlit surface) color.
</ParamField>

<ParamField path="image" type="string | HTMLImageElement">
  Optional source image to apply the paper texture over as a filter.
</ParamField>

<ParamField path="contrast" type="number" default="0.3">
  Blending behavior controlling the sharpness of the light/shadow transitions. Range: `0` to `1`.
</ParamField>

<ParamField path="roughness" type="number" default="0.4">
  Pixel-level noise intensity. Related to canvas pixels and not scalable. Range: `0` to `1`.
</ParamField>

<ParamField path="fiber" type="number" default="0.3">
  Intensity of the curly fiber noise layer. Range: `0` to `1`.
</ParamField>

<ParamField path="fiberSize" type="number" default="0.2">
  Scale of the fiber noise. Smaller values produce finer fibers. Range: `0` to `1`.
</ParamField>

<ParamField path="crumples" type="number" default="0.3">
  Intensity of the cell-based crumple pattern. Range: `0` to `1`.
</ParamField>

<ParamField path="crumpleSize" type="number" default="0.35">
  Scale of the crumple pattern cells. Range: `0` to `1`.
</ParamField>

<ParamField path="folds" type="number" default="0.65">
  Depth of the fold/crease deformation. Range: `0` to `1`.
</ParamField>

<ParamField path="foldCount" type="number" default="5">
  Number of folds applied to the surface. Range: `1` to `15`.
</ParamField>

<ParamField path="fade" type="number" default="0">
  Big-scale noise mask applied to the texture. Higher values fade the pattern toward the edges. Range: `0` to `1`.
</ParamField>

<ParamField path="drops" type="number" default="0.2">
  Visibility of speckle/water-drop pattern. Range: `0` to `1`.
</ParamField>

<ParamField path="seed" type="number" default="5.8">
  Seed applied to folds, crumples, and drops. Changing this value produces a different surface configuration. Range: `0` to `1000`.
</ParamField>

<ParamField path="speed" type="number" default="0">
  Animation speed. Paper texture is static by default (`speed: 0`).
</ParamField>

<ParamField path="frame" type="number" default="0">
  Static frame position when `speed` is `0`.
</ParamField>

## Presets

| Name | Description |
|------|-------------|
| `Default` | Realistic blue-grey paper with balanced texture |
| `Cardboard` | Brown cardboard with strong fiber and crumples |
| `Abstract` | High-contrast abstract surface in cyan and magenta |
| `Details` | Maximum detail mode with transparent colors for use as an overlay |
