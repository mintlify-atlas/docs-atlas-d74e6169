Paper Shaders is a collection of 28 GPU-accelerated WebGL shaders for React and vanilla JavaScript. Each shader is available as a React component from `@paper-design/shaders-react` or as a raw fragment shader string from `@paper-design/shaders` for use with `ShaderMount`.

## Animated shaders

<CardGroup cols={2}>
  <Card title="Mesh Gradient" href="/shaders/mesh-gradient">
    A flowing interplay of color spots, moving along distinct trajectories and transformed by organic distortion.
  </Card>
  <Card title="Static Mesh Gradient" href="/shaders/static-mesh-gradient">
    Multi-point mesh gradients with up to 10 color spots, enhanced by two-direction warping, adjustable blend sharpness, and grain controls.
  </Card>
  <Card title="Static Radial Gradient" href="/shaders/static-radial-gradient">
    Radial gradient with up to 10 blended colors, featuring advanced focal point control, shape distortion, and grain effects.
  </Card>
  <Card title="Simplex Noise" href="/shaders/simplex-noise">
    A multi-color gradient mapped into smooth, animated curves, delivering a sleek, futuristic visual.
  </Card>
  <Card title="Grain Gradient" href="/shaders/grain-gradient">
    Multi-color gradients with grainy, noise-textured distortion available in 7 animated abstract forms.
  </Card>
  <Card title="Pulsing Border" href="/shaders/pulsing-border">
    Luminous trails of color merging into a glowing gradient frame.
  </Card>
  <Card title="Color Panels" href="/shaders/color-panels">
    Glowing translucent 3D panels rotating around a central axis.
  </Card>
  <Card title="Smoke Ring" href="/shaders/smoke-ring">
    Radial multi-colored gradient shaped with layered noise for a natural, smoky aesthetic.
  </Card>
  <Card title="Neuro Noise" href="/shaders/neuro-noise">
    A glowing, web-like structure of fluid lines and soft intersections. Great for creating atmospheric, organic-yet-futuristic visuals.
  </Card>
  <Card title="Dot Orbit" href="/shaders/dot-orbit">
    Animated multi-color dots pattern with each dot orbiting around its cell center. Supports up to 40 colors and various shape and motion controls.
  </Card>
  <Card title="Dot Grid" href="/shaders/dot-grid">
    Static grid pattern made of circles, diamonds, squares or triangles.
  </Card>
  <Card title="Metaballs" href="/shaders/metaballs">
    Up to 20 gooey blobs moving around the center and merging into smooth organic shapes.
  </Card>
  <Card title="Perlin Noise" href="/shaders/perlin-noise">
    Animated 3D Perlin noise with exposed controls.
  </Card>
  <Card title="Voronoi" href="/shaders/voronoi">
    Anti-aliased animated Voronoi pattern with smooth and customizable edges.
  </Card>
  <Card title="Waves" href="/shaders/waves">
    Static line pattern configurable into textures ranging from sharp zigzags to smooth flowing waves.
  </Card>
  <Card title="Warp" href="/shaders/warp">
    Animated color fields warped by noise and swirls, applied over base patterns (checks, stripes, or split edge). Blends up to 10 colors.
  </Card>
  <Card title="God Rays" href="/shaders/god-rays">
    Animated rays of light radiating from the center, blended with up to 5 colors.
  </Card>
  <Card title="Spiral" href="/shaders/spiral">
    A single-colored animated spiral that morphs across a wide range of shapes.
  </Card>
  <Card title="Swirl" href="/shaders/swirl">
    Animated bands of color twisting and bending, producing spirals, arcs, and flowing circular patterns.
  </Card>
  <Card title="Dithering" href="/shaders/dithering">
    Animated 2-color dithering with multiple pattern sources (noise, warp, dots, waves, ripple, swirl, sphere).
  </Card>
  <Card title="Paper Texture" href="/shaders/paper-texture">
    A static texture built from multiple noise layers, usable for realistic paper and cardboard surfaces or abstract patterns.
  </Card>
</CardGroup>

## Image filters

<CardGroup cols={2}>
  <Card title="Fluted Glass" href="/shaders/fluted-glass">
    Fluted glass image filter transforms an image into streaked, ribbed distortions, giving a mix of clarity and obscurity.
  </Card>
  <Card title="Water" href="/shaders/water">
    Water-like surface distortion with natural caustic realism. Works as an image filter or animated texture without image.
  </Card>
  <Card title="Image Dithering" href="/shaders/image-dithering">
    A dithering image filter with support for 4 dithering modes and multiple color palettes.
  </Card>
  <Card title="Heatmap" href="/shaders/heatmap">
    A glowing gradient of colors flowing through an input image, creating a smoothly animated wave of intensity.
  </Card>
  <Card title="Liquid Metal" href="/shaders/liquid-metal">
    Futuristic liquid metal material applied to an uploaded logo or one of the pre-defined abstract shapes.
  </Card>
  <Card title="Halftone Dots" href="/shaders/halftone-dots">
    A halftone-dot image filter featuring customizable grids, color palettes, and dot styles.
  </Card>
  <Card title="Halftone CMYK" href="/shaders/halftone-cmyk">
    A halftone CMYK classic algorithm image filter.
  </Card>
</CardGroup>
